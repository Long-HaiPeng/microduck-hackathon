# 装配与校准

> 板卡与引脚核对状态见 [BOM.md](BOM.md)；适用于当前方案（自行组装玩具＋FlashDuck 壳）和备选 Otto ESP32-S3 套件。

## 鸭形固件适配（待真机验收）

`otto-duck` 是独立构建变体，仍使用当前小智/Otto 基线和 linx。
旧左手插口控制嘴巴，旧右手插口控制脖子；不再运行人形挥手、举手动作。
它复用原板引脚，不能用于替代板卡接线核对。
以下配置适用于仓库的自有固件，不能直接套用到实拍版本；具体区别见[演示与仓库固件](../firmware/README.md#演示与仓库固件)。

- 默认嘴巴闭合/打开为 45°/60°，脖子范围 105°–165°、中位 135°。
  这是待校准的起始配置，不代表打印件已适配；先拆下摇臂负载确认方向和行程。
- 鸭形行走采用宽站距参数：髋部内收 25°、髋摆幅 44°、脚摆幅 34°、相位 108°，
  起始值参考 [FlashDuck 步态说明](https://github.com/FlashCat-Jordan/Flashduck/blob/main/firmware/voice/main/boards/flashduck/README.md)。
  本固件在 `menuconfig` 配置这些参数，不读取官方固件的 NVS 调参结果；实际步态和方向待真机校准。
- 在 `menuconfig -> Otto duck mechanics and display` 调整中位、范围和眼睛窗口。
  微调另存于 `duck_trims`，不读取原 `otto_trims`；嘴巴为 `mouth`、脖子为 `neck`。
- 无摄像头配置中右手和屏幕 CS 同为 GPIO12。鸭形固件检测到冲突时禁用全部动作、
  `self.otto.get_status` 返回 `disabled`；先核对实际板卡，再添加已验证的独立引脚配置。
- 单眼窗口默认左上角 `(72,22)`、大小 `96×96` 像素，底部滚动显示状态、
  激活码和系统提示。窗口不是 CAD 尺寸，必须按实际开孔位置调整。
- 鸭形停止、断网停止和超时只取消动作并保持最后输出；不会自动再动一遍归位。
  确认结构无阻挡后，显式调用 `home`。保持输出不是切断电源，堵转应断电。

编译（在固件目录且已经加载 ESP-IDF 6.1 环境）：

```sh
python3 scripts/build.py otto-robot --name otto-duck --language zh-CN --wake-word wn9_xiaoyaxiaoya_tts2
```

此命令选择“小鸭小鸭”唤醒模型，生成本地构建，不烧录。需要人工确认实物后再授权烧录。
如果用 `menuconfig` 修改装配参数，后续用 `idf.py build` 保留本地配置；
再次调用上述标准构建命令会重建配置，回到变体默认值。

最小验收：架空 `home` → 左右小幅转头 → 单次 `quack` → 一步行走；
分别在动作刚提交和动作中停止、断网，确认不续跑；再发 `home` 验证恢复。
确认各关节方向和运动范围后，再分别验证 `sit` 和 `dance`，不要直接按视频效果推断机械参数已匹配。
连续试验需记录固件版本、板型、角度、窗口位置和视频。主机测试/编译成功不能替代此验收。

## 玩具组装路线

1. 先通电测试原厂语音、屏幕、动作、充电和按键，录像记录设备版本与故障。
2. 记录原厂固件版本、设备序列号和灵矽绑定状态；确认可解绑、可恢复后再拆壳。
3. 下载 FlashDuck 对应底座版本的打印配置，先打印配合件试装，不要一次打完整套。
4. 按卖家图示拆原外壳，保留所有螺丝、屏幕排线、电池和舵机线位。
5. 装入打印鸭壳后先架空上电，确认舵机行程和线束没有被新外壳卡住。
6. 原厂固件可完成语音演示时先用原厂系统验收硬件；只有确认引脚和烧录方式后才刷入本项目固件。

## 所需工具

- PH0/PH00 小十字螺丝刀
- 小斜口钳，用于修整舵机摇臂
- 可传输数据的 Type-C 线
- 干净桌面和架空测试用的支架

无需焊接、3D 打印机、万用表或第二块主控。

## 开箱

1. 录制完整开箱视频，拍清快递面单和外包装。
2. 按 BOM 清点打印件、舵机、屏幕、扬声器、电池、开关和螺丝。
3. 检查电池是否鼓包、接口是否破损、线束是否有断线。
4. 清理打印件支撑，疏通舵机孔、螺丝孔和轴承位。

## 首次上电和舵机回中

1. 先不安装腿，只连接主控、六个舵机、扬声器和电池。
2. 打开电源，确认屏幕点亮和固件启动。
3. 按所选固件确认中位：腿脚约 90°；原 Otto 左右手约 45°/135°；
   鸭形嘴巴/脖子按上节配置。不要把全部六个关节强行装在 90°。
4. 断电后拆下舵机线，开始机械装配。

如果舵机没有回中，停止装配，先检查固件、电源和线序。

## Otto 套件机械装配

1. 用舵机包内的大螺丝固定腿部舵机。
2. 修整十字摇臂，把摇臂装到腿部，保持方向一致。
3. 腿部圆柱突起朝屏幕侧，腿朝前，避免明显内八或外八。
4. 用指定形状的摇臂安装脚部，线束穿回身体。
5. 固定扬声器、电池、天线、主控和屏幕。
6. 所有线束避开腿部运动范围，盖好头盖。

螺丝拧紧即可，不要压裂打印件，也不要让排线被挤压。

## 首次校准

1. 架空机器人，逐项检查舵机响应、方向和 HOME。
2. 小程序/控制台或 MCP `self.otto.set_trim` 一次调整 1–5°。
3. 如果 `otto-duck` 单个关节需要超过 ±10° 才能回正，先检查舵机齿位和装配方向；原 Otto 关节若需超过约 ±20°，也先检查装配。
4. 动作结束后必须能回到 HOME；出现堵转、异响或供电复位立即断电。

## 分层动作测试

| 顺序 | 测试 | 通过条件 |
| --- | --- | --- |
| 1 | 架空舵机测试 | 六路方向正确，无卡死 |
| 2 | HOME/坐下 | 平滑回位，不顶限位 |
| 3 | 支撑下走路 | 动作顺序正确，线束不缠绕 |
| 4 | 地面走三步 | 连续 3 次无跌倒 |
| 5 | 原地转向 | 左右各 3 次 |
| 6 | 语音动作 | 语音结束后动作在目标时延内开始 |
| 7 | 语音停止 | 动作停止、不续跑；鸭形保持输出，单独发 home 后才归位 |
| 8 | 执行中断网 | 目标 2 秒内停止步态；鸭形不自动归位，重连后不续跑（需实测） |

## 灵矽联调（仓库原 Otto 变体）

1. 配置 Wi-Fi。
2. 设备请求灵矽 OTA 并显示/朗读激活码。
3. 在灵矽控制台绑定设备并重启。
4. 依次测试对话、前进、后退、转向、坐下、挥手和停止。

`otto-duck` 的动作集合见本文开头；[实拍版本](../firmware/README.md#演示与仓库固件)使用其自身的动作工具和配置。
