# 装配与校准

> 适用于当前方案“六舵机成品玩具＋FlashDuck 打印壳”，以及备选的 Otto ESP32-S3 套件。

## 烧录前的兼容性门槛

当前尚未锁定具体卖家板卡的型号和版本。到货后必须取得板卡版本及引脚表，并与固定上游 `otto-robot` 配置核对舵机、音频和屏幕接口。仅证明“卖家原厂固件能运行”不够；核对前不得烧录后直接驱动舵机。

板卡型号锁定后，应补充对应接线表。没有该表时，本文件只覆盖机械装配，不提供经验性引线猜测。

## 成品玩具路线

1. 先通电测试原厂语音、屏幕、动作、充电和按键，录像记录设备版本与故障。
2. 记录原厂固件版本、设备序列号和灵矽绑定状态；确认可解绑、可恢复后再拆壳。
3. 下载 FlashDuck 对应底座版本的打印配置，先打印配合件试装，不要一次打完整套。
4. 按卖家图示拆原外壳，保留所有螺丝、屏幕排线、电池和舵机线位。
5. 装入打印鸭壳后先架空上电，确认舵机行程和线束没有被新外壳卡住。
6. 原厂固件可完成语音演示时先用原厂系统验收硬件；只有确认引脚和烧录方式后才刷入本项目固件。

## 所需工具

- PH0/PH00 小十字螺丝刀
- 小斜口钳，用于修整舵机摇臂
- 可传输数据的 Type-C 线
- 干净桌面和架空测试用的支架

无需焊接、3D 打印机、万用表或第二块主控。

## 开箱

1. 录制完整开箱视频，拍清快递面单和外包装。
2. 按 BOM 清点打印件、舵机、屏幕、扬声器、电池、开关和螺丝。
3. 检查电池是否鼓包、接口是否破损、线束是否有断线。
4. 清理打印件支撑，疏通舵机孔、螺丝孔和轴承位。

## 首次上电和舵机回中

1. 先不安装腿，只连接主控、六个舵机、扬声器和电池。
2. 打开电源，确认屏幕点亮和固件启动。
3. 等舵机回到约 90° 中位，期间不要堵转或强拧齿轮。
4. 断电后拆下舵机线，开始机械装配。

如果舵机没有回中，停止装配，先检查固件、电源和线序。

## Otto 套件机械装配

1. 用舵机包内的大螺丝固定腿部舵机。
2. 修整十字摇臂，把摇臂装到腿部，保持方向一致。
3. 腿部圆柱突起朝屏幕侧，腿朝前，避免明显内八或外八。
4. 用指定形状的摇臂安装脚部，线束穿回身体。
5. 固定扬声器、电池、天线、主控和屏幕。
6. 所有线束避开腿部运动范围，盖好头盖。

螺丝拧紧即可，不要压裂打印件，也不要让排线被挤压。

## 首次校准

1. 架空机器人，逐项检查舵机响应、方向和 HOME。
2. 小程序/控制台或 MCP `self.otto.set_trim` 一次调整 1–5°。
3. 如果单个关节需要超过约 ±20° 才能回正，先检查舵机齿位和装配方向。
4. 动作结束后必须能回到 HOME；出现堵转、异响或供电复位立即断电。

## 分层动作测试

| 顺序 | 测试 | 通过条件 |
| --- | --- | --- |
| 1 | 架空舵机测试 | 六路方向正确，无卡死 |
| 2 | HOME/坐下 | 平滑回位，不顶限位 |
| 3 | 支撑下走路 | 动作顺序正确，线束不缠绕 |
| 4 | 地面走三步 | 连续 3 次无跌倒 |
| 5 | 原地转向 | 左右各 3 次 |
| 6 | 语音动作 | 语音结束后动作在目标时延内开始 |
| 7 | 语音停止 | 任意动作都能停止并归位 |
| 8 | 执行中断网 | 2 秒内停止步态、清空队列，5 秒内归位；重连后不续跑 |

## 灵矽联调

1. 配置 Wi-Fi。
2. 设备请求灵矽 OTA 并显示/朗读激活码。
3. 在灵矽控制台绑定设备并重启。
4. 确认 WSS hello、音频和 `tools/list`。
5. 依次测试对话、前进、后退、转向、坐下、挥手和停止。

## 3D 打印边界

打印件是结构件，不是纯外观件：身体固定主控和电池，腿是传动连杆，脚是接地面。套件不含打印件时，使用官方模型或卖家同版结构，不要混用不同舵机和连杆版本。
