# MicroDuck Hackathon

基于现成六舵机套件与社区鸭形外壳的桌面机器人原型。项目围绕语音与实体动作交互展开，代码工作集中在**带 Otto 机器人支持的小智固件二次开发**，语音后端使用灵矽（linx）。

[观看实物 Demo](docs/media/demo.mp4) · [构建固件](firmware/README.md#构建) · [装配与校准](hardware/ASSEMBLY.md)

## 项目构成

| 部分 | 采用的方案 | 本项目的工作 |
| --- | --- | --- |
| 硬件 | 现成 ESP32-S3 六舵机套件，复用主板、屏幕、音频和电池 | 装配、接线与调试 |
| 外壳 | FlashDuck 社区 3D 打印模型 | 打印与结构装配 |
| 固件 | 小智固件（含 Otto 板级适配与动作控制） | **二次开发**：鸭形动作与显示适配、语音交互调整、动作保护及问题修复 |
| 语音服务 | 灵矽提供 ASR、LLM、TTS 和设备工具调用 | 设备端接入与联调 |

组件的固定版本与许可见[固件说明](firmware/README.md#来源与许可)。

## 固件二开内容

- **鸭形动作**：新增 `otto-duck` 变体，将原双臂通道用于脖子和嘴巴，提供独立限位、校准与 20 种动作。
- **动作控制**：白名单、参数范围、单动作接收、超时与停止处理；修复普通 Otto 控制器的动作入队竞争。
- **语音交互**：灵矽配置、按键切换与 PTT（按住说话）适配，修复模式接管、松手及被打断后的播放处理。
- **音频与显示**：为已有 AEC 框架接入播放参考并修复缓冲/重采样问题，增加小窗口眼睛、状态和辅助显示。

具体动作、接口、代码入口和验证记录见 [系统架构](docs/ARCHITECTURE.md)。

## 开始使用

1. 查看[硬件准备](hardware/ASSEMBLY.md#硬件准备)，核对套件与打印件是否匹配。
2. 按 [固件说明](firmware/README.md#构建)选择变体并构建。
3. 按 [装配与校准](hardware/ASSEMBLY.md)核对板型、关节方向和行程，再进行烧录及逐项验收。

项目范围与后续方向见[产品与商业思考](docs/PRODUCT.md#项目范围)。
