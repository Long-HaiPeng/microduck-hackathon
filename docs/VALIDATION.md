## 协议测试

1. 设备请求灵矽 OTA，取得激活码。
2. 完成账号绑定，重新请求 OTA，确认返回 WebSocket 地址和 token。
3. 建立 WSS，收到 server hello 和 session id。
4. `tools/list` 返回 Otto 工具。
5. `tools/call` 调用 `self.otto.get_status` 并收到响应。
6. 普通对话、连续对话、弱网重连各跑一轮并保存日志。

## 动作白名单

| 请求 | 期望结果 |
| --- | --- |
| `walk, steps=3` | 执行三步后归位 |
| `walk, steps=100` | 拒绝或裁剪到 10 步 |
| `jump` | 拒绝 |
| `turn, speed=100` | 拒绝或裁剪到 800ms |
| 任意舵机序列 | 返回禁用错误 |
| 动作执行中再次调用 | 返回 busy |
| 动作执行中调用 `stop` | 不返回 busy；500ms 内停止步态，2 秒内归位 |
| 动作执行中短按实体键 | 优先停车，不切换对话状态 |

## 实体动作

架空检查六路舵机方向、90° 中位、堵转、异响和供电复位。地面检查前进、后退、左右转向各 3 次，以及坐下、回家、挥手和摇摆。每项记录成功次数和失败现象。

## 语音与安全

- 同一动作意图至少测试三种自然说法。
- 记录从用户说完到动作开始的时延。
- TTS 播放中直接说新指令，确认当前播报停止并进入下一轮对话。
- TTS 播放中短按实体键，确认播报清空并进入下一轮监听。
- 连续做 10 次播报中打断，记录误触发次数、响应时延和是否残留旧音频。
- 用较大音量播放 TTS，确认机器人不会把自己的声音识别成用户。
- 在慢速长动作中拔网线或关闭 AP，确认 2 秒内停止步态、清空队列，5 秒内归位。
- 网络恢复后确认旧动作不会续跑。
- 构造超过 30 秒的动作，确认本地 watchdog 停止并归位。
- 低电量时确认机器人停止动作并提示充电。
